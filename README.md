# @marie-christ/maketou

A community-maintained TypeScript SDK for the Maketou API.

> This is an independent community-maintained SDK for the Maketou API. It is not an official Maketou package and is not affiliated with or endorsed by Maketou.

## Status

This package is under active development. It is designed for server-side TypeScript applications that integrate Maketou checkout and cart-status operations.
